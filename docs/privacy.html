Anime Release Calendar

Privacy Policy

Last updated: 27 October 2026

This extension shows a weekly anime release calendar and links each episode on Crunchyroll. This page describes exactly what it touches.

Summary

The extension sends no data to the developer or to any third-party server. There is no analytics, no tracking, no advertising, and no account of any kind. Everything it reads stays inside your own browser.

What the extension accesses

Your Crunchyroll session

To show which series are in your queue or in a Crunchylist, the extension needs to talk to Crunchyroll as you. It never asks for your password and never reads your cookies. Instead, while you are on crunchyroll.com, it observes the authorization header that the Crunchyroll page itself already sends with its own requests, and reuses it.

  • Kept in chrome.storage.session, which lives in memory only and is erased when the browser closes.
  • Never written to disk and never sent anywhere except crunchyroll.com, which issued it.
  • Discarded immediately if Crunchyroll rejects it.

Your Crunchyroll queue and Crunchylists

Read only to mark and filter releases in the calendar. The titles are kept in chrome.storage.session, which is memory only and is erased when the browser closes, so reopening the calendar in the same session does not request them again. They are never written to disk and never transmitted anywhere.

Changing your queue and Crunchylists

The extension can add a series to, or remove it from, your Crunchyroll queue or one of your Crunchylists. It does so only when you click the control on a card, and only for the series on that card. It never changes anything on its own, and it cannot create, rename or delete a list.

Your language preference

Stored locally so the interface opens in the language you chose.

A cache of public series identifiers

Stored locally to avoid repeating lookups. These identifiers are public catalog data, not personal information.

Network requests

The extension contacts only these hosts, and only for the stated purpose:

HostPurpose
graphql.anilist.coFetch the weekly release schedule (public API, no account)
www.crunchyroll.comRead your queue and Crunchylists, resolve episode links, and apply the add or remove you asked for — all using your existing session
www.anidachi.appBackup schedule source, used only if AniList fails

No request carries any identifier created by the extension.

What the extension does not do

  • Does not collect or transmit personal information.
  • Does not sell or share data with anyone.
  • Does not use data for advertising, credit, or lending purposes.
  • Does not read pages other than crunchyroll.com.
  • Does not load or execute remote code; all code ships inside the package.

Permissions

Removing your data

Uninstalling the extension removes everything it stored. Closing the browser already clears the session token.
